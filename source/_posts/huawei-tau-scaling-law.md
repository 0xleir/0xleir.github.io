2026年5月25日，华为董事、半导体业务总裁何庭波在上海 IEEE ISCAS 2026 国际会议上正式提出"韬(τ)定律"——一个旨在替代摩尔定律几何缩微路径的新半导体演进原则。本文尝试从技术原理出发，客观评价其创新性、可行性和局限性。

<!-- more -->

## 一、为什么需要新路径：摩尔定律的困境

### 摩尔定律在放缓

摩尔定律——集成电路上晶体管数量约每两年翻倍——正在明显放缓。Intel 前CEO Pat Gelsinger 2023年承认"现在更接近每三年翻倍"；NVIDIA CEO黄仁勋2022年直接宣布摩尔定律已死[1]。

### 物理极限：原子尺度的墙

几何缩微面临的是原子尺度的硬性天花板。当晶体管栅极接近几个原子宽度（<1nm）时：

- 量子隧穿效应使栅极无法有效控制沟道电流
- 原子级波动导致器件间特性差异不可控
- 源漏泄漏电流无法抑制

目前最先进的"2nm"制程，栅极实际物理尺寸约12nm（"2nm"是商业命名）。行业共识是几何缩微还剩2-3代空间（约到2030年前后）[1]。

### 还有一个被忽视的问题：布线瓶颈

即便晶体管能继续缩小，线宽缩小带来的电阻飙升正在抵消收益。先进制程下，信号延迟的主要瓶颈已从晶体管本身转移到芯片内部的布线互连上——这正是韬定律试图解决的核心问题。

### 行业早已在探索替代路径

2016年，国际半导体技术路线图（ITRS）发布最后一版基于摩尔定律的路线图，转向"More than Moore"策略[1]。AMD的chiplet架构[3]、NVIDIA的系统级集成、Intel的Foveros 3D封装，都在"不纯粹依赖缩小晶体管"的方向上探索。韬定律并非凭空出现，而是这一大趋势下的一个具体理论框架。

## 二、韬(τ)定律：核心思想

### 从"缩小"到"缩短"

韬定律的核心主张：用**时间缩微**替代**几何缩微**。

不再追求把晶体管做得更小，而是系统性地压缩信号传播延迟时间常数τ。

### 时间常数τ是什么

在数字电路中，信号从A传到B的延迟由RC时间常数决定：

**τ = R × C**

- R = 导线电阻（线越细，R越大）
- C = 寄生电容（面积越大，C越大）

传统摩尔定律缩小晶体管来减小C，但线宽缩小同时增大了R，导致RC延迟反而恶化。韬定律的思路是跳出这个死循环，从多个层面同时压缩τ：

- **器件级**：优化晶体管开关速度（如更高迁移率沟道材料）
- **电路级**：减少关键路径逻辑级数
- **芯片级**：通过3D堆叠缩短布线物理距离
- **系统级**：芯片间互连优化（更短封装走线、片上光互连）

### 数学表达

- τ = f(τ_transistor, τ_circuit, τ_chip, τ_system)
- 代际规则：τ(n+1) / τ(n) ≤ 1/α
- α因场景而异：移动端约1.3倍/年，AI场景可达10倍/年

**本质区别**：几何缩微是"做更小的东西来做更多"，时间缩微是"把东西放更近、路径走更短来做更快"。

### 命名

"韬"取自中文韬略（深藏、大战略），τ是物理学中的时间常数符号，构成双语双关。

## 三、关键技术：逻辑折叠

### 原理

传统芯片所有电路铺在同一层——如同一座城市全是平房，城市越大、通信路径越长。

逻辑折叠类似于把平房改建多层楼：将电路"折叠"到垂直堆叠的多层有源硅片中，层间通过超细间距混合键合（<2μm）连接。

```
传统2D布局：              逻辑折叠后：
┌───────────────────┐     ┌──────────┐
│ A ──────────── B  │     │ A ─── B  │ ← 第2层
│                   │     ├──────────┤
│ C ──────────── D  │     │ C ─── D  │ ← 第1层
└───────────────────┘     └──────────┘
  长信号路径                短信号路径（垂直互连极短）
```

### 效果

- **布线缩短**：横跨芯片的长线变为垂直方向短互连
- **RC延迟降低**：线更短 → R更小、C更小 → τ更小
- **密度提升**：同一投影面积内垂直堆多层，等效密度翻倍
- **无需更先进光刻**：每层用同一制程，通过叠层而非缩小来提升

### 与传统3D封装的关键区别

传统3D封装是把存储芯片堆在处理器上方（如HBM），功能模块之间的堆叠。逻辑折叠是将**同一个处理器的逻辑电路本身**拆分到多层——难度远大于前者，因为逻辑电路内部信号交互密度比存储器高得多。

**截至目前，行业尚无商业化的3D堆叠逻辑核心**[2]。现有商用3D产品仅限于存储（NAND、HBM）和I/O层。如果华为真正实现了有源逻辑层的3D堆叠量产，这将是一个真正的行业首次。

## 四、硅验证数据：麒麟2026

华为公布的麒麟2026芯片数据（已硅验证，计划用于Mate 90）：

| 指标 | 提升幅度 |
|------|----------|
| 晶体管密度 | 155 → 238 MTr/mm²（+53%） |
| 性能核能效 | +41% |
| 最大主频 | 3.1GHz（+13%） |
| 布线长度 | -30% |
| 时钟偏差 | -25% |

华为声称性能等效于台积电第一代3nm / Intel 18A制程，并给出路线图：

- 2027：麒麟2027，3.39GHz
- 2029：>4GHz
- 2031：等效1.4nm密度（400+ MTr/mm²）

华为称过去6年已基于该原则量产381款芯片，覆盖手机、基站、汽车、AI。

## 五、τ路径的物理极限

摩尔定律撞的是"空间的墙"。如果τ路径可行，它将撞的是"时间和热量的墙"：

### 1. 光速极限

信号在铜导线中以约60-70%真空光速传播。无论怎么缩短路径，传播时间不可能低于距离÷光速。芯片尺寸足够小时，这个极限会显现。

### 2. 热力学极限（Landauer极限）

每次不可逆位操作至少耗散 kT·ln2 能量（~3×10⁻²¹ J/bit @ 300K）。更快开关 = 更高功率密度，而3D堆叠让散热更困难——功率密度与时间常数之间存在根本对抗。

### 3. 材料RC极限

- 电阻R：铜的电阻率约1.7μΩ·cm，这是物理下限；纳米尺度下表面散射和晶界散射进一步恶化
- 电容C：low-k介质的介电常数已接近可制造性极限（目前约k=2.0-2.5，理论下限为真空的1）

即使3D堆叠把路径缩到最短，单位长度RC仍受材料物理性质约束。

### 4. 堆叠层数极限

每增一层：散热压力增大、良率以乘法下降、对准精度要求更高。NAND能堆200+层是因为存储单元功耗极低；逻辑芯片功耗密度高1-2个数量级，可堆层数远少于存储。

### 小结

两条路径的物理极限不同但都存在。更可能的情况是互补：几何缩微耗尽后，时间缩微提供额外几代演进空间，但最终同样趋近天花板。

## 六、评估难题：多变量框架如何验证

τ = f(τ_transistor, τ_circuit, τ_chip, τ_system) 涉及四个层级、多个变量，导致一个核心问题：当厂商声称"τ缩小30%"时，外界如何验证？

摩尔定律下评估很直观——数晶体管、量栅极长度。但τ框架下，变量间存在复杂权衡：

| 优化手段 | τ改善 | 副作用 |
|----------|-------|--------|
| 增加堆叠层数 | 缩短布线 → τ↓ | 散热恶化、良率下降 |
| 更低k介质 | 电容↓ → τ↓ | 机械强度降低、可靠性风险 |
| 更细间距键合 | 层间距↓ → τ↓ | 对准精度要求更高、成本上升 |
| 电路级流水线重划分 | 关键路径级数↓ → τ↓ | 面积增加、功耗上升 |
| 系统级互连优化 | 片间延迟↓ → τ↓ | 设计复杂度大增 |

同一个τ数字可以通过不同组合达成，但用户体验可能截然不同。激进堆叠获得的低τ可能伴随降频散热，持续性能反而不如保守方案。

**可行的评估方式：**

1. **端到端benchmark**：Geekbench、SPEC不关心路径，只看结果
2. **能效比（perf/watt）**：τ缩小伴随功耗飙升则意义有限
3. **持续性能 vs 峰值性能**：散热受限下两者差异可能很大
4. **等效节点对标**：将密度和性能与台积电/Intel已知制程对比
5. **独立拆解**：TechInsights等机构可验证堆叠层数、键合间距等物理参数

何庭波论文也承认"需要全新基准测试框架"——在新标准建立前，最可靠的判据仍然是量产真机的实际体验。

## 七、争议与质疑

### "定律"不是宣布出来的

摩尔定律是1965年基于观察的经验总结，经数十年全行业验证后才成为共识。韬定律是一家公司在一次会议上主动命名宣布的。"定律不是被宣布出来的，而是被验证出来的。"

### 散热：3D逻辑堆叠的核心难题

3D IC领域公认的首要挑战[2]：热量在堆叠内积聚，电学接近 = 热学接近，局部热点管理复杂度剧增。在手机等封闭散热场景下能否持续满载，量产前无法确证。

### 时间线差距

台积电/三星/Intel预计2027-2028量产1.4nm制程。华为"等效1.4nm"目标是2031年——通过替代路径晚3-4年。当然，对无法获取EUV的华为而言，"晚到"远好于"永远到不了"。

### 品牌包装 vs 科学突破

底层技术（3D堆叠、chiplet、架构协同）在AMD/Intel/NVIDIA/TSMC均有布局。华为的独特之处是将它们统一在τ为核心度量的理论框架下。这是理论创新还是概念包装？尚无第三方独立验证。

### 论文自我承认的局限

- EDA工具链尚未针对原生3D设计就绪
- 晶圆间工艺偏差管控未解决
- 垂直互连开销因负载而异
- 缺乏能耗伴随原则（τ管时间，不管能量）
- 需要全新基准测试框架

## 八、本文观点

韬定律的技术路径是真实且有价值的。在制裁约束下，华为走出了一条不依赖EUV的演进路线，逻辑折叠和系统级协同优化是务实的工程选择，硅验证数据具备说服力。

但将其命名为"定律"并与摩尔定律并列，更多是战略传播的考量。这不一定是坏事——清晰的叙事框架有助于凝聚团队、对齐产业链。只是我们应该区分"有效的工程策略"和"行业公认的客观规律"。

真正的考验：

1. 麒麟2026量产后的实际表现、良率、成本
2. 其他厂商是否跟进采纳类似框架
3. 多代产品能否持续验证τ缩放的可预测性

如果五年后全行业都在用类似方法论，那它或许真能成为一条定律；如果只有华为在用，那它就是一套优秀的企业技术战略——这也已经足够值得尊敬。
